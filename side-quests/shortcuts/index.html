התקנה

  1. פותחים את הדף הזה ב-Safari באייפון ולוחצים "הורדה".
  2. "הוספת קיצור דרך", ומקלידים את הקוד של 6 הספרות כשהוא מבקש (פעם אחת לכל קיצור).

📥 ל-SQ: איך משתמשים

  1. ביוטיוב, אינסטגרם, Safari או כל אפליקציה: שיתוף ← ל-SQ. אם הוא לא בשורה, גוללים לסוף שורת האפליקציות ← "עוד" ← מוסיפים אותו למועדפים (פעם אחת).
  2. אפשר להוסיף משפט או להכתיב (🎤 במקלדת), למשל "לדשבורד הבריאות" או "לבדוק אם כדאי לקנות". אפשר גם להשאיר ריק.
  3. הודעה "📥 נשמר" ונגמר. תוך שעה הוא נקרא, מתויק לדשבורד או למשימה המתאימה עם תובנות, ומופיע עם סימן "חדש".
  4. בלי שיתוף (מהווידג׳ט או מהאפליקציה Shortcuts) הוא לוקח את מה שהעתקת.

🚘 סייד לוקיישן ברכב: אוטומציה לבלוטוס (פעם אחת)

מורידים קודם את "סייד לוקיישן" למעלה. לחיצה רגילה עליו פותחת תפריט "איפה אני", ובנוסף יוצרים שתי אוטומציות, כשהבלוטוס של הרכב כבר מחובר לאייפון לפחות פעם אחת:

  1. אפליקציית Shortcuts ← לשונית "אוטומציה" ← + ← Bluetooth.
  2. "מכשיר" ← בוחרים מהרשימה גם את הפורד וגם את הקיה (לא צריך להקליד שמות) ← מסמנים "מחובר".
  3. מסמנים "הפעלה מיידית" ומכבים "הודעה בעת הפעלה" ← הבא.
  4. שתי פעולות: קודם "טקסט" וכותבים בו driving, ואחריה "הפעלת קיצור דרך" ← סייד לוקיישן (הקלט שלה = הטקסט) ← סיום.
  5. עוד אוטומציה אחת, אותו דבר עם "מנותק", ושתי פעולות: קודם "טקסט" וכותבים בו auto, ואחריה "הפעלת קיצור דרך" ← סייד לוקיישן (הקלט שלה = הטקסט).

מתחבר: האפליקציה עוברת ל"🚘 נוהג" ומציגה רק משימות שאפשר לעשות בשיחת טלפון (לשעתיים או עד הניתוק). מתנתק: חוזרת לאוטומטי, והמיקום נבדק שוב כשפותחים אותה.
